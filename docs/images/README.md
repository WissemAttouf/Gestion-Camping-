# Captures d’écran — Gestion Camping

Déposez dans ce dossier les captures d’écran réelles de l’application Gestion Camping.

Noms de fichiers conseillés :
- `accueil.png` — page d’accueil
- `campings.png` — liste ou gestion des campings
- `reservations.png` — gestion des réservations

Après l’ajout des images, elles pourront être affichées dans le README principal avec des chemins relatifs, par exemple : `![Page d’accueil](docs/images/accueil.png)`.
